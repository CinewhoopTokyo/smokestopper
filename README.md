# Smoke Stopper

ドローン用 短絡保護治具の取扱説明書。

**取扱説明書 → https://cinewhooptokyo.github.io/smokestopper/**

組み上げたドローンの初回通電を、電流を制限した状態で行うための治具です。
電流・電圧・ピーク電流・負荷抵抗を数値で表示し、異常があれば自動で遮断します。

```
入力        USB-C PD  9V / 15V / 20V
出力        XT60 / XT30
電流上限     0.1 / 0.3 / 0.5 / 0.8 / 1.2 A
表示        有機EL 0.91インチ 128×32
外形        50.6 × 44.7 mm
```
